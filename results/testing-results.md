# Testing Results

## 📌 Overview

This file contains the testing results of the **Smart Irrigation Monitoring System**.

The prototype was tested under different soil conditions to verify automatic irrigation control.

---

## 🧪 Testing Conditions

The system was tested using different:

- Plants
- Soil types
- Soil moisture conditions

The response of the water pump was observed for each condition.

---

---

## ✅ Observations

The testing showed that:

- Low soil moisture activated the water pump.
- Wet soil conditions turned the pump OFF.
- Moisture conditions affected the irrigation response.
- The system provided automatic irrigation control.
- Pump status was indicated using the red and green LEDs.

---

## 📌 Final Result

The prototype successfully demonstrated automatic irrigation control based on the detected soil moisture condition.

The test results support the use of the system for automated irrigation monitoring and control.
