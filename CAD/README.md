# CAD Design

## 📌 Overview

This folder contains the CAD modelling and design documentation of the **Smart Irrigation Monitoring System** prototype.

The CAD model represents the physical arrangement and overall structure of the developed irrigation system.

---

## 📐 CAD Views

The CAD documentation includes the following views:

- Isometric View
- Top View
- Front View
- Right-Side View

---

## 🧩 CAD Model

The 3D CAD model is used to visualize the overall arrangement of the Smart Irrigation Monitoring System prototype.

It helps to understand the positioning and arrangement of the major system components.
